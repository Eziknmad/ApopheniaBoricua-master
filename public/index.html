01 / Features

Three working systems

Built and tested

Document-grounded tutor

A web app built around a from-scratch transformer project. It answers from the project's own documents and code, quotes the exact passages, and draws a document map. Every answer shows where it came from.

195 tests pass.

Limit: runs offline on a local laptop.

Built and tested

Multi-agent Orchestrator

A Coordinator splits a task, parallel workers run the pieces, and an Assembler collects the results in order. In the demo it audits 72 project documents with rule checkers. A C11 shell host can embed it in native code.

9 tests pass for the slice.

Limit: the checkers are rules, not reasoning. They don't prove a claim is true.

Built and tested

BunkHouse Chess

Four-player bughouse chess on two devices. A WebSocket relay holds the one true game and checks every move. Captured pieces pass to your partner. An ECO opening book names the opening as you play.

Smart contract: 29 of 29 tests pass on a local chain. Checked by rules

Limit: the contract is not deployed or audited.

Supporting work: the C11 Core Engine

A ten-node graph engine written in C11. It is a separate component, not yet wired to the Orchestrator.

  • Built and tested Node 1: 371 of 371 checks pass.
  • Designed but not built Nodes 2–10.

02 / Research case

Trading research: an honest coin flip

A data collector records 1-second EURUSD_otc prices from a DEMO account, and the experiment's rules were written down before any result. The question: when the price moves one way, does it keep going?

49.8%

Right 9,929 times out of 19,925, which is chance level. No edge was found, and that's reported as it is.

DEMO-only research. No live trading, no real money, no profit claimed. Not part of the Orchestrator.
